# Print-on-Demand T-Shirt Shop — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a live print-on-demand t-shirt shop where the owner edits the catalogue in a Payload admin panel with no redeploy, and a Stripe sandbox purchase is marked paid only by a signature-verified webhook.

**Architecture:** One Next.js App Router application with Payload 3 mounted inside it, backed by two separate Supabase Postgres projects (development and production). Product photos live in Vercel Blob. Payment runs through Stripe's hosted Checkout; the browser is redirected to Stripe and never handles an amount. An order row is created `pending` when the Checkout Session is made and flipped to `paid` only by the webhook handler after signature verification. Every deploy is performed by GitHub Actions — Vercel's own git deploys are disabled in `vercel.json`.

**Tech Stack:** Next.js (App Router) · TypeScript · Payload 3 · `@payloadcms/db-postgres` · `@payloadcms/storage-vercel-blob` · Supabase Postgres · Stripe Node SDK · Tailwind CSS · Vitest · Playwright · Vercel · GitHub Actions

**Spec:** `docs/superpowers/specs/2026-09-04-shop-design.md`

---

## Global Constraints

Every task's requirements implicitly include this section.

- **Node 22 LTS.** Pinned in `.nvmrc` and `package.json` `engines`. Vercel's runtime tops out at Node 22; building on anything newer builds on something production never runs.
- **Prices are integers in minor units (cents).** Never a float, anywhere — collection field, Stripe `unit_amount`, order snapshot, tests.
- **One currency, application-wide constant.** `EUR`. Not a per-product field.
- **The server never accepts a price, name or amount from the client.** Every amount sent to Stripe is read from the database inside the same request.
- **The success page has no authority.** It reads and displays; it never marks anything paid.
- **`DATABASE_URI` uses Supabase's session-mode pooler.** Transaction mode does not support prepared statements, which Payload's Drizzle adapter uses.
- **Vercel Blob uses `clientUploads: true`.** Vercel caps server uploads at 4.5 MB; mockup photos exceed it.
- **Our HTTP handlers live outside `/api`.** Payload 3 mounts its REST API at `/api/[...slug]`. Our two handlers are `/shop/checkout` and `/shop/stripe-webhook`.
- **No database credential ever enters GitHub Actions secrets.** Only `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID`.
- **Stripe stays in sandbox.** `sk_test_` / `pk_test_` only. No account activation, no live keys, ever.
- **Shop name:** `Overprint` (provisional — see spec §13; change before Task 3 or live with it).

```ts
import { NextResponse } from 'next/server'
import { getPayload } from 'payload'
import configPromise from '@payload-config'
import { stripe } from '@/lib/stripe'
import { CURRENCY } from '@/lib/constants'

export const runtime = 'nodejs'

export async function POST(req: Request) {
  const body = await req.json().catch(() => null)
  const productId = body?.productId

  if (!productId) {
    return NextResponse.json({ error: 'productId is required' }, { status: 400 })
  }

  const payload = await getPayload({ config: configPromise })

  // The price comes from the database. Nothing in the request body is trusted.
  const product = await payload
    .findByID({ collection: 'products', id: productId, depth: 0 })
    .catch(() => null)

  if (!product) {
    return NextResponse.json({ error: 'Product not found' }, { status: 404 })
  }

  if (product.soldOut) {
    return NextResponse.json({ error: 'This design is sold out' }, { status: 409 })
  }

  const origin = process.env.NEXT_PUBLIC_SERVER_URL

  const session = await stripe.checkout.sessions.create({
    mode: 'payment',
    line_items: [
      {
        quantity: 1,
        price_data: {
          currency: CURRENCY,
          unit_amount: product.price,
          product_data: { name: product.name },
        },
      },
    ],
    success_url: `${origin}/order/success?session_id={CHECKOUT_SESSION_ID}`,
    cancel_url: `${origin}/products/${product.slug}`,
  })

  // Pending now; only the verified webhook may mark it paid.
  await payload.create({
    collection: 'orders',
    overrideAccess: true,
    data: {
      stripeCheckoutSessionId: session.id,
      status: 'pending',
      amountTotal: product.price,
      items: [
        {
          product: product.id,
          nameSnapshot: product.name,
          unitAmountSnapshot: product.price,
          quantity: 1,
        },
      ],
    },
  })

  return NextResponse.json({ url: session.url })
}
```

```ts
import { NextResponse } from 'next/server'
import { getPayload } from 'payload'
import configPromise from '@payload-config'
import { stripe } from '@/lib/stripe'
import type Stripe from 'stripe'

export const runtime = 'nodejs'

const ok = () => NextResponse.json({ received: true })

export async function POST(req: Request) {
  const signature = req.headers.get('stripe-signature')

  if (!signature) {
    return NextResponse.json({ error: 'Missing signature' }, { status: 400 })
  }

  // The raw body, unparsed — signature verification depends on the exact bytes.
  const rawBody = await req.text()

  let event: Stripe.Event
  try {
    event = stripe.webhooks.constructEvent(
      rawBody,
      signature,
      process.env.STRIPE_WEBHOOK_SECRET as string,
    )
  } catch {
    return NextResponse.json({ error: 'Invalid signature' }, { status: 400 })
  }

  if (event.type !== 'checkout.session.completed' && event.type !== 'checkout.session.expired') {
    return ok()
  }

  const session = event.data.object as Stripe.Checkout.Session
  const payload = await getPayload({ config: configPromise })

  const { docs } = await payload.find({
    collection: 'orders',
    where: { stripeCheckoutSessionId: { equals: session.id } },
    limit: 1,
    overrideAccess: true,
  })

  const order = docs[0]
  if (!order) return ok()

  if (event.type === 'checkout.session.expired') {
    if (order.status === 'pending') {
      await payload.update({
        collection: 'orders',
        id: order.id,
        overrideAccess: true,
        data: { status: 'expired' },
      })
    }
    return ok()
  }

  if (session.payment_status !== 'paid') return ok()
  if (order.status === 'paid') return ok()   // replayed event

  await payload.update({
    collection: 'orders',
    id: order.id,
    overrideAccess: true,
    data: {
      status: 'paid',
      paidAt: new Date().toISOString(),
      stripePaymentIntentId:
        typeof session.payment_intent === 'string' ? session.payment_intent : undefined,
      email: session.customer_details?.email ?? undefined,
    },
  })

  return ok()
}
```

```tsx
import { formatPrice } from '@/lib/constants'

export const dynamic = 'force-dynamic'

export default async function SuccessPage({
  searchParams,
}: {
  searchParams: Promise<{ session_id?: string }>
}) {
  const { session_id: sessionId } = await searchParams

  if (!sessionId) {
    return (
      <main className="mx-auto max-w-xl p-8">
        <h1 className="text-2xl font-bold">No order to show</h1>
        <Link href="/" className="mt-4 inline-block underline">Back to the shop</Link>
      </main>
    )
  }

  const payload = await getPayload({ config: configPromise })
  const { docs } = await payload.find({
    collection: 'orders',
    where: { stripeCheckoutSessionId: { equals: sessionId } },
    limit: 1,
    overrideAccess: true,
  })

  const order = docs[0]

  if (!order) {
    return (
      <main className="mx-auto max-w-xl p-8">
        <h1 className="text-2xl font-bold">We could not find that order</h1>
        <Link href="/" className="mt-4 inline-block underline">Back to the shop</Link>
      </main>
    )
  }

  // This page reports what the database says. It never marks anything paid —
  // only the verified webhook does that.
  const isPaid = order.status === 'paid'

  return (
    <main className="mx-auto max-w-xl p-8">
      <h1 className="text-2xl font-bold">
        {isPaid ? 'Thank you — your order is paid' : 'Confirming your payment…'}
      </h1>

      {!isPaid && (
        <p className="mt-2 text-neutral-600">
          Stripe is confirming this with us. Refresh in a moment.
        </p>
      )}

      <ul className="mt-6 divide-y rounded-lg border">
        {order.items?.map((item, index) => (
          <li key={index} className="flex justify-between p-4">
            <span>
              {item.nameSnapshot} × {item.quantity}
            </span>
            <span>{formatPrice(item.unitAmountSnapshot)}</span>
          </li>
        ))}
      </ul>

      <p className="mt-4 flex justify-between font-medium">
        <span>Total</span>
        <span>{formatPrice(order.amountTotal)}</span>
      </p>

      <Link href="/" className="mt-8 inline-block underline">Back to the shop</Link>
    </main>
  )
}
```

> The page shows the line items from the **order snapshot**, not from the live product. If the owner changes a price after the sale, this page keeps showing what was charged.
